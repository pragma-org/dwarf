03 / tap architecture

Measurement sources stay separate from the test verdict.

Stock

Signals that the unmodified node already exposes: logs, network state, ledger events, and process state.

External

Observer-side evidence: workload accounting, process and cgroup resources, health, chain tips, restart gates, and sync endpoints.

Patched

Revision-locked internal timing taps. They retain integer elapsed_nanos, keep elapsed_micros, and report fractional microseconds.

Reserved

A declared source class for future instrumentation. It makes absence explicit; it is not fabricated evidence.

Flow: exact target → raw source records → normalized collectors → window correlation → report and raw evidence → dashboard → signed export/import. Assertions read evidence but measurement thresholds do not gate by default.

Precision rule: collectors prefer nanoseconds when present. For example, 2184 ns becomes 2.184 µs. Legacy whole-microsecond records still load. Card 03 stays on whole-microseconds-v1.

Four selectable measurement profiles: amaru-security-default and cardano-security-default select compatible Stock and External taps. amaru-security-patched and cardano-security-patched add only the implemented revision-locked Patched taps. Reserved definitions are not silently enabled.

Child-friendly explanationSome measuring marks are already on the machine, some sit outside it, and some were added inside an exact copy. All marks send notes to the same evidence box.

The first Amaru topology did not prove an active Plutus V2 cost model. The additive topology uses a Cardano producer and Amaru consumer, pins genesis and parameters, activates the model on chain, and retains real transaction evidence. Fresh separate runs now also account for all 60 offered transactions, bytes, outcomes, and known-outcome durations on each implementation.

Forks / semantic correction

The old strict raw-event monotonic rule was incorrect because legitimate same-height switches can occur. The new model preserves raw history and evaluates bounded canonical progress, convergence, correlations, and health separately.

What resolution does not mean

A later pass does not rewrite an earlier failure. A topology repair does not prove every Plutus workload. A converged fork test does not prove freedom from all deep-chain behavior.
