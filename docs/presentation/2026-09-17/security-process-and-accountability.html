September 17 · operating agreement

Every security signal gets an owner and a next action

One evidence-led lifecycle separates node defects, interoperability gaps, harness failures, platform faults, and valuable negative results.

Decision requested: adopt the lifecycle, ownership matrix, private-first reporting rule, and required finding record in DWARF’s root SECURITY.md.

Signal to verified closure

The state follows the supported claim—not the run’s pass/fail label.

01

Preserve

Keep evidence private, immutable, and secret-free.

02

Prove

Target, setup, reachability, and non-vacuity.

03

Classify

Scope, novelty, severity, and demonstrated impact.

04

Report

Send the minimal private reproducer to its owner.

05

Track

Fix, accepted risk, duplicate, or invalid reason.

06

Verify

Original plus neighboring cases on exact fixed build.

07

Close

Coordinate disclosure, credit, and retained evidence.

One run can contain several truths

A passing security property, a real node availability bug, and a harness-invalid signal can coexist. Classify each claim independently.

Primary accountability by scope

“Joint” never means ownerless: one party still owns the next action.

DWARF product DWARF maintainer

Controller, dashboard, evidence, packaging, or secret handling. Fix, regression-test, package, disclose.

Harness / oracle Scenario owner

Setup, identity, fault scope, observer, or vacuous assertion. Repair and rerun before a node claim.

Cardano-node Node maintainers

Haskell node ledger, consensus, networking, or runtime. Private report; DWARF verifies the fixed build.

Amaru Node maintainers

Rust node ledger, consensus, networking, or runtime. Private report; DWARF verifies the fixed build.

Interoperability / spec Joint technical owners

Same input, different outcome, ownership unknown. Identify the governing rule and assign remediation.

Moog / Antithesis Platform maintainer

Launch, orchestration, fault injection, or platform runtime. Preserve platform evidence; make no SUT claim.

Dependency / infrastructure Component owner

Registry, CI, OS, or third-party library. Track DWARF exposure and verify mitigation.

Unknown DWARF triage owner

Evidence cannot yet distinguish scope. Keep private and gather discriminating evidence.
