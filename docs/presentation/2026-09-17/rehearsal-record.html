What this proves

Launch path

Mixed topology
Real Cardano-node and native Amaru relay processes ran together with expected identities and remained healthy.

What this does not prove

Precise claim boundary: the assertion queries a Cardano-node consumer whose only upstream path is through the native Amaru relays. It does not directly query a native Amaru tip. This supports an Amaru-fed convergence inference, not direct native-tip equivalence.
Not an adversarial campaign
No faults were injected. This is a clean epoch-boundary differential observation chosen for a short, deterministic live demo.
Not universal correctness
Three passes cover these revisions, inputs, and histories only.
Not throughput evidence
The samples show liveness and agreement; they do not measure offered load, admission, inclusion, adoption, or internal node latency.
Not a physical click
The exact GUI backend endpoint is proven. The presenter must still rehearse the literal browser interaction and visible button state.

Repaired rehearsal blocker

Harness/deployment issue — not a node finding

Initial run 20260910T054653Z-c283bf85 failed immediately because the hardened dashboard container had no Docker client. The catalog scenario path had not been routed through the existing restricted host control channel.

Revision 0cf2ca4 added an exact-catalog-only scenario <id> command to the forced-command shim. It did not mount the Docker socket or grant arbitrary host execution. Seventy-two related tests passed on cardano-box, followed by the 3/3 runtime proof above.
